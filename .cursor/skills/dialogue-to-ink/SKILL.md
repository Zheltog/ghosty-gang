# Диалог в Ink

Собери текст пользователя в `.ink` этого проекта. Полный список тегов — `docs/ink tags.md`, прочитай его до первой реплики. Соседние `.ink` той же сцены важнее догадки: id персонажей, клипы, предметы и окна бери оттуда.

Текст реплик не переводи и не приукрашивай. Новый `character_name`, клип, окно, id предмета или `action` не выдумывай.

## Сначала спроси

Не пиши файл, пока нет ответов. Спрашивай пачкой, по делу, и не схлопывай пункты в один общий вопрос. Если пользователь говорит «как в такой-то сцене» — открой её `.ink` и перечисли, что взял, коротким списком на подтверждение.

1. **Файлы.** Сколько историй. У каждой `# story:` — короткое имя. Какой заход отдельный файл (разговор, осмотр, предмет), а что `INCLUDE` внутрь одной истории. Общие узлы реакций — инклуд, не вторая история.
2. **Кто говорит.** `character_name` со сцены для каждого. Какие строки — речь (`# char`), какие — мысль (`# thought`), какие — фраза игрока (`# response`). Кого в кадре не рисовать и на каких репликах. Кто уходит и когда (`# away:id`). Если id нет в `Scripts/Dialog/CharacterNames.gd` — спроси, добавлять ли туда экранное имя. В ink имя не пишется.
3. **Позы и эмоции.** Для каждого персонажа готовые имена `pose` и `anim` из его спрайтов. Какая поза липкая. Где клип называется целиком, без префикса позы.
4. **Окна.** Имена `window` этой сцены и какое держать по умолчанию.
5. **Клик.** Какие реплики ждут клик, какие идут сами (`# skippable:false`). В уже написанных диалогах речь чаще идёт сама, мысли и `# response` чаще ждут клик — не копируй это молча.
6. **Реакции.** Какие предметы (id инвентаря, нижний регистр) и какие `action` прерывают разговор, на каких репликах, в какой узел. Вернуться на ту же реплику (`:back`) или уйти из ветки. Висеть, пока игрок не сделает действие (`# react_wait`), или говорить дальше. Что записать в переменные. Чем кончается необратимое (выстрел и подобное): `-> END` или нет.
7. **Переменные между файлами.** Имя, тип, старт, кто пишет, кто только читает.
8. **Конец файла.** Куда выходит история, какие флаги ставит. `EXTERNAL` / `~ godot_1(...)` — только если пользователь назвал событие сцены. Имя события не выдумывай.

Если развилок много, следующим сообщением покажи только узлы и переходы, без текста реплик. Полный `.ink` — после подтверждения.

Файлы клади в `Files/SceneDialogs/Ink/`, если пользователь не назвал другой путь. В шапке файла — одна-две строки, о чём он.

## Файл и общие переменные

Каждый `.ink` — отдельная история со своими `VAR`. Между историями ходят только имена из шапки. Шапка — строки `#`, `VAR`, `EXTERNAL`, `INCLUDE` и комментарии до первой реплики.

```ink
# story: interview
# load: gun_drawn, suspicion
# save: gun_drawn

VAR gun_drawn = false
VAR suspicion = 0
```

`# load` в начале подставляет уже сохранённое. `# save` в конце забирает обратно. Имя без `VAR` в этом файле пропускается. Списки могут различаться: чужое только читают, своё пишут. В `INCLUDE` те же переменные; `VAR` там не повторять.

`*` — вариант один раз, `+` — снова. Текст выбора часто повторяется следующей строкой с `# response`. `%%` в строке показывает варианты в этой точке и из текста вырезается.

```ink
-> start

=== start ===
Над входом написано «ПРОДУКТЫ». # window:default # thought
Чего вам? # char:cashier # anim:bored # skippable:false
* [Сигарет.]
    Сигарет. # response
    -> END
```

## Теги, которых нет в шпаргалке

- `# thought` — мысль. Без `# char` говорящий `none`. С `# char` мысль от этого персонажа, и `anim` играет на нём.
- `# response` без `# char` — говорящий `detective`, окно `player_phrase`. Липкое `# window` не меняется.
- `# introduced` — персонаж назвал себя. Игра запоминает `{id}_introduced`.
- `# away:id` — персонаж уходит из кадра. Пустой `# away` — тот, кто говорит эту строку.
- `# pose` липнет к персонажу, пока её не сменят. `# anim` играет клип `pose_anim`. Если значение совпало с позой или позы нет — клип равен значению. Пустая `# pose:` сбрасывает позу.
- `# char` — только эта строка. `# char_default` — пока не сменят. Новая история начинается ни с кем.

## Реакции

Строка слушает инвентарь, пока висит на экране. Формат: `событие:предмет:узел` или `action:имя:узел`, хвост `:back` необязателен. Несколько штук через запятую в одном теге. Пробелов в частях нет.

События: `pickup`, `equip`, `equip_start`, `unequip`, `unequip_start`. `action` — действие надетого предмета (`shoot`, `drink`).

- `# react` заменяет набор только на этой строке. Пустой `# react:` — строка глухая, даже если есть липкий набор.
- `# react_default` липнет с этой строки дальше. Пустой сбрасывает. Чтобы снять его перед выходом из узла, поставь сброс отдельной строкой без текста.
- `# react_wait` — строка висит, пока не сработает реакция или видимый вариант. Клик и автопродолжение её не двигают.
- Без `:back` прыжок в текущем потоке. Из туннеля `->->` возвращает туда, откуда туннель вызвали. Флаги (`~ gun_drawn = false`) пиши в узле реакции.
- `:back` уводит реакцию в отдельный поток, прерванная реплика остаётся на месте. Узел кончай `-> DONE`: та же реплика, те же варианты и реакции показываются снова. `->->` в `:back`-узле не писать. `-> END` кончает весь диалог из любого потока.
- Реакция без `:back` внутри `:back`-узла остаётся в том же потоке и при исчерпании тоже вернёт на прерванную реплику.

Так это уже сделано для пистолета: меню остаётся на месте, ствол уходит в туннель и возвращается, пока игрок не выстрелит.

```ink
Что вам ещё рассказать? # char:engineer # pose:sit # anim:normal # skippable:false # react:equip:gun:gun_back:back
+ [О мальчике.]
    -> boy

=== gun_back ===
-> gun ->
-> DONE

=== gun ===
~ gun_drawn = true
Уберите его! # char:engineer # anim:scared # skippable:false # react_default:unequip:gun:gun_down, action:shoot:gun_kill # react_wait
->->

=== gun_down ===
~ gun_drawn = false
Спасибо. # char:engineer # anim:normal # skippable:false
# react_default:
->->

=== gun_kill ===
# react_default:
~ engineer_dead = true
-> END
```
